
#
  Reactive Resume 功能设计书

##
  一、项目简介

  Reactive Resume 是一款 免费、开源（MIT 协议）的在线简历制作工具，定位是让用户在一个网页里就能完成"选模板 → 填内容 → 实时预览 → 导出 / 分享"的全流程，并以"自托管 / 零追踪 / 数据归用户所有"为核心卖点。

  本次选用的版本已默认中文界面，但仍保留面向全球用户的形态：英文社交账号登录、海外招聘习惯的模板字段、国外大模型厂商等。

  目标用户：

     |

     |

     |

     |

     |

     |

     |

     |

        单位内部 / 学校 / 机构

     |

     |

        自托管部署，供员工或学生使用

  本次设计目标：保留全部现有功能，仅以"叠加"方式补齐中文体验、国内登录方式、国内招聘场景、国产服务对接、国内合规这五类中国用户必备的能力。

##
  二、现有功能清单（保留项）

  下列功能均已实现，本次改造 全部保留，仅在其上叠加新功能。

###
  2.1 账号与登录

  邮箱 + 密码注册 / 登录

  邮箱验证、改邮箱、找回 / 重置密码

  Google / GitHub / LinkedIn 社交登录

  Passkey（免密码登录）、两步验证（TOTP + 备用码）

  用户名（用于公开简历 URL）

  通用 OAuth Provider 对接

###
  2.2 简历编辑（Builder）

  三栏布局：左栏表单 / 中栏 A4 实时预览 / 右栏设计面板

  内置分区：个人信息、个人简介、工作经历、证书、奖项、教育、技能、语言、项目、出版物、推荐人、志愿经历、兴趣、自定义分区

  富文本编辑、拖拽排序、撤销与版本历史、JSON Patch 自动保存

  颜色 / 字体 / 间距 / 页面尺寸（A4 / Letter）自定义

###
  2.3 模板

  15 套宝可梦命名模板（Azurill、Pikachu、Gengar、Lapras 等）

  已支持 CJK 字体回退（思源黑体、苹方、华文黑体等）

###
  2.4 导出与分享

  PDF（浏览器端生成，无需外部服务）

  DOCX（Word 文档，可继续编辑）

  Markdown、JSON（备份 / 还原 / 二次编辑）

  公开分享链接（`{username}/{slug}`）

  公开页访问密码保护

  浏览 / 下载次数统计（30 天趋势）

  Open Graph / Twitter Card 链接预览

###
  2.5 求职申请管理（Application Tracker）

  看板 / 表格 / 洞察三种视图

  阶段：Saved / Applied / Screening / Interview / Offer / Rejected

  标签、备注、时间线、联系人、跟进日期、薪资、来源

  关联本系统的简历、CSV 导入 / 导出、批量操作、归档

###
  2.6 AI 能力

  用户自配 AI Provider：Anthropic Claude、Cohere、DeepSeek、Fireworks、Google Gemini、Groq、Mistral、Ollama Cloud、OpenAI、OpenRouter、Perplexity、xAI Grok

  Builder 内 AI 助手、Application Copilot（评分 / 定制 / 起草）、AI Agent 工作区

  简历解析与改写（PDF / Word / JSON Resume 导入）

###
  2.7 管理后台

  概览（用户数 / 简历数 / 注册趋势 / 存储用量）

  用户管理（角色 / 封禁 / 删除）

  简历管理（锁定 / 删除）

  审计日志（所有写操作留痕）

  运行时开关（注册、邮箱登录、限流等）+ SMTP 状态查看

###
  2.8 工程能力

  ATS 简历检查器

  Command Palette（Cmd+K 全局搜索 / 跳转）

  MCP Server（用 AI 客户端管理简历和求职）

  API Key + OpenAPI 接口

  暗 / 亮模式、40+ i18n（含 RTL）

##
  三、新增功能（重点）

    分类说明：

    替代类：现有能力依赖国外组件，改用国产 / 中文替代

    新增类：项目原本没有、中国用户场景下新增的能力

###
  3.1 中文体验增强

####
  ① 中文简历模板包【替代类 · 高】

  做什么：在 Builder 模板库新增 3–4 个中文简历模板，覆盖"单页标准"、"校招版"、"国企 / 事业单位版"、"中英对照版"等典型版式

  为什么：现有 15 个模板以宝可梦命名、采用西式排版，国内求职者（尤其投递国企 / 事业单位 / 公务员 / 应届生校招）习惯单页紧凑、彩色证件照、个人信息横条、时间倒序的版式

  放哪里：Builder 右栏 Design → 模板选择器，缩略图加"中文"标识

####
  ② 中文简历专用字段【替代类 · 高】

  做什么：个人信息分区增加国内简历特有字段：政治面貌、民族、籍贯、证件照、身高、婚姻状况、期望岗位、期望城市、期望薪资、到岗时间

  为什么：投递国企 / 事业单位 / 公务员岗必备；现有个人信息分区只有英文简历常见的字段

  放哪里：Builder 左栏"个人信息"区块，字段可单独隐藏；导出时按模板自动取舍

####
  ③ 中文字体扩充【替代类 · 中】

  做什么：字体选择器新增常用中文字体：思源黑体、思源宋体、霞鹜文楷、阿里巴巴普惠体、方正书宋

  为什么：现有 CJK 回退字体只解决"能显示"，用户主动选择中文样式字体时选择少，影响 PDF 排版观感

  放哪里：Builder 右栏 Design → 字体选择器

####
  ④ 中文简历 OCR 导入【新增类 · 中】

  做什么：导入对话框新增"拍照 / 上传图片识别"入口，用户上传图片简历后系统自动识别并结构化填充各字段

  为什么：国内很多用户的简历是手机拍照、聊天截图、扫描件等图片格式；现有"智能解析导入"只支持 PDF / Word

  放哪里：Dashboard 或 Builder → 导入简历 → 新增"图片识别"标签

###
  3.2 国内登录方式

####
  ⑤ 微信扫码登录【新增类 · 高】

  做什么：登录页增加"微信登录"按钮，弹出二维码，手机微信扫一扫后确认完成登录 / 注册

  为什么：国内 PC 端用户最习惯的登录方式之一；现有登录只有邮箱和 Google / GitHub / LinkedIn，国内用户覆盖率低

  放哪里：`/auth/login` 页"其他登录方式"区

####
  ⑥ 手机号 + 短信验证码登录【新增类 · 高】

  做什么：登录页新增"手机号登录"标签：输入手机号 → 收 6 位短信码 → 自动注册或登录；老用户首次绑定手机号后可二选一

  为什么：国内移动互联网标配；邮箱在国内年轻用户群体渗透率偏低

  放哪里：`/auth/login` 顶部 Tab 切换"邮箱 / 手机号"

####
  ⑦ 支付宝扫码登录【新增类 · 中】

  做什么：登录页增加"支付宝登录"按钮，扫码后确认授权登录

  为什么：支付宝在国内除支付外也是常用身份登录方式之一，可作为补充

  放哪里：与微信登录并排

###
  3.3 国内投递与分享

####
  ⑧ 国内招聘平台格式适配【替代类 · 高】

  做什么：导出对话框新增"招聘平台投递"选项，预设三种常用格式：BOSS 直聘图片简历、猎聘 PDF、拉勾 / 智联 PDF

  为什么：国内招聘平台格式偏好不同（BOSS 偏好图片简历，猎聘 / 智联偏好 PDF）；用户一份简历通用不够

  放哪里：Builder 顶栏 Download 对话框 → 新增"招聘平台投递"分区

####
  ⑨ 简历图片卡 / 名片卡分享【新增类 · 中】

  做什么：分享区新增"生成简历图 / 名片卡"，输出适合朋友圈、微信好友、QQ 空间分享的长图或单页图

  为什么：国内社交分享首选图片格式（朋友圈、小红书）；现有分享只有 URL 和 PDF

  放哪里：Builder 右栏 Sharing → 新增"生成图片卡"按钮

####
  ⑩ 公开简历二维码名片【新增类 · 中】

  做什么：分享区增加"下载二维码名片"按钮，HR 或候选人现场扫码即可查看简历

  为什么：国内招聘现场（宣讲会、双选会、行业沙龙）常用二维码代替纸质简历交换

  放哪里：Builder 右栏 Sharing → 与"复制公开链接"并排

###
  3.4 国产服务对接（功能角度）

####
  ⑪ 国产大模型接入【替代类 · 高】

  做什么：AI Providers 设置中增加国产模型选项：通义千问、文心一言、豆包、Kimi、智谱 GLM（DeepSeek 已支持）

  为什么：国内用户更习惯国产大模型；可与国外模型并存让用户自选

  放哪里：Settings → AI Providers → Provider 下拉新增 5 项；可提供"国内模型一键默认"开关

####
  ⑫ 国产短信服务接入【替代类 · 中】

  做什么：管理后台增加"短信服务"设置区，可选阿里云短信、腾讯云短信，配置 AccessKey、签名、模板 ID

  为什么：配合手机号登录功能使用，国内短信必须用持牌服务商

  放哪里：管理后台 Settings → 新增"短信服务"页签

####
  ⑬ 国产对象存储接入【替代类 · 低】

  做什么：管理后台"存储设置"中增加选项"使用阿里云 OSS / 腾讯云 COS / 华为云 OBS"，替代现有 S3 配置

  为什么：国内服务器自托管时更倾向用国产对象存储

  放哪里：管理后台 Settings → Storage 选项区

###
  3.5 国内合规

####
  ⑭ 中文隐私政策与用户协议【替代类 · 中】

  做什么：登录页、注册流程、设置页增加中文版《隐私政策》《用户协议》链接；首次注册需勾选同意

  为什么：合规要求（《个人信息保护法》《数据安全法》）；现有系统只有英文 README

  放哪里：登录页底部 + 注册流程勾选框 + Settings → Legal 入口

####
  ⑮ 实名认证【新增类 · 低】

  做什么：用户设置中增加"实名认证"，填姓名 + 身份证号，通过后简历页显示"已实名"标志

  为什么：投递部分国企 / 事业单位 / 考公场景可能要求简历实名；增强平台真实性

  放哪里：Settings → Profile → 实名认证入口
